Assignment 04 — Grade Book with IF Function

WEEK 3 • Advanced Work

အဆင့်သတ်မှတ်စာရင်း:

  1. Column A–D: အမည်၊ အမှတ် ၃ ခု
  2. Column E: Average =AVERAGE(B2:D2)
  3. Column F: Grade — =IF(E2>=80,"A",IF(E2>=60,"B",IF(E2>=40,"C","F")))
  4. Column G: Pass/Fail — =IF(E2>=40,"Pass","Fail")
